# Restaurante La Fonda - Plataforma Web

## Descripción
Plataforma web desarrollada para mejorar la presencia digital del restaurante La Fonda y facilitar la consulta de productos, realización de pedidos, promociones, delivery o recojo y otras funciones orientadas al cliente.

## Funcionalidades principales
- Visualización de la carta
- Registro e inicio de sesión
- Carrito de compras
- Registro de pedidos
- Promociones y cupones
- Delivery o recojo
- Pago
- Historial de pedidos
- Reseñas

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- Bootstrap
- Supabase
- PostgreSQL
- Git y GitHub

## Estructura del proyecto
- index.html
- vistas/
- css/
- js/
- assets/

## Base de datos
La plataforma utiliza PostgreSQL mediante Supabase para almacenar información relacionada con usuarios, productos, pedidos, pagos y demás operaciones.

## Ejecución
1. Clonar el repositorio.
2. Abrir el proyecto en Visual Studio Code.
3. Configurar la conexión con Supabase.
4. Ejecutar mediante un servidor local.

## Integración
Los pedidos registrados mediante la plataforma web pueden ser utilizados posteriormente por el sistema interno de escritorio del restaurante.
