Una sola autoridad para el stock

La web no modifica stock operativo. Las cantidades preparadas, ingredientes y stock diario continúan siendo responsabilidad del sistema de escritorio y de PostgreSQL. Aquí solo se consulta el estado que los RPC actuales exponen.

Qué debes hacer con el stock

Configura y actualiza el stock diario desde el sistema de escritorio. La web intentará leer ese mismo stock en modo consulta con los permisos actuales de Supabase; si la lectura está protegida, PostgreSQL seguirá validándolo al registrar el pedido. La web no enviará valores de stock paralelos.
